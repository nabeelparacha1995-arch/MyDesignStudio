# MyDesign Studio — Android starter app

A native Android starter prototype built with Kotlin and Jetpack Compose.

## Included in this starter
- Home screen and clothing categories
- Product selection
- Customization options for fabric, base colour, embroidery, neckline, sleeves and length
- Standard size selection and basic custom measurements
- Estimated price calculation
- Cart summary

## Open in Android Studio
1. Unzip the project.
2. In Android Studio, choose **Open** and select the `MyDesignStudio` folder.
3. Use JDK 17 or the JDK recommended by your Android Studio version.
4. Allow Gradle sync to complete.
5. Run the `app` configuration on an emulator or Android device.

## Important
This is a front-end starter/demo. Product images are represented by simple placeholders.
Login, backend, database, real garment rendering, order management, delivery, and payment
gateway integration are not included yet. The displayed price is a sample estimate and
should be replaced with your actual tailoring and fabric pricing rules.

Package name: `com.example.mydesignstudio`
